## 6a. Доставка владельцу: компактная сводка (ТЗ-5-доп-2)

Внешняя проверка нашла дефект доставки: для заданий `no_agent` планировщик
Hermes отдаёт владельцу **ровно stdout обёртки**, а `scripts/common/tuber_report.sh`
печатал только строку-подтверждение `Tuber report: объединённая выдача собрана …`.
Сам отчёт (91 строка) оставался файлом на сервере — владелец суточную выдачу в
чате не видел. Legacy-поведение было другим: X-отчёт печатал компактную сводку.

Закрыто:

- **`tuber report --compact`** — сводка для доставки: заголовок (что, окно
  `--days`, путь к базе, дата); по каждой платформе — пункты в том же виде, что и
  в полном отчёте (русское описание, цифры, ПОЛНАЯ ссылка); секция
  сквозного сюжета — одной строкой (сколько сюжетов или «нет»); подвал — сколько
  пунктов скрыто по каждой платформе и путь к полному файлу. Правила ранжирования
  в сводку не печатаются: о них и полном списке сообщает одна строка подвала.
- **Обёртка** `scripts/common/tuber_report.sh` вызывает `--compact` и печатает
  сводку в stdout (это и уходит владельцу); полный отчёт по-прежнему пишется
  файлом (`--save --out reports/`) и **целиком** идёт в журнал. Строка-подтверждение
  из stdout убрана, `ALERT Tuber report: …` при rc≠0 сохранён.
- **Бюджет 3500 знаков** (байт UTF-8). Считается по длине UTF-8 (строже числа
  знаков для кириллицы, поэтому и `wc -c` укладывается в лимит, а лимит Telegram —
  4096). Места делятся СПРАВЕДЛИВО (ТЗ-5-доп-3): **резерв** — каждый раздел с
  данными получает минимум 1 пункт; остаток бюджета — **round-robin** по одному
  следующему пункту за шаг, пока пункт влезает целиком (порядок внутри раздела —
  сверху вниз). Если резерв не влезает, укорачивается только ОПИСАНИЕ пункта (с
  многоточием); ссылка и цифры не меняются — владелец проверяет ссылки кликом.
- Сводка печатается и когда полный отчёт не сохранялся (в подвале — пометка).
- Режим `--compact` не меняет `--json` и обычный вывод без флага.

ТЗ-5-доп-3 (17.09.2026) закрыло содержательный дефект доп-2: обрезка «с конца»
оставляла последнюю секцию (на живой базе — Telegram) без пунктов целиком.
Теперь строка «все пункты скрыты» не печатается НИКОГДА: раздел без данных честно
сообщает «нет данных за окно» (пунктов нет в данных, а не в бюджете), а у каждого
раздела с данными гарантированно есть хотя бы один пункт. Счётчики скрытых
печатаются всегда, и «показано + скрыто» по каждому разделу сходится с числом
пунктов раздела в полном отчёте.

Пример — `docs/REPORT-TZ5-example-compact.txt`: фактический `wc -c` = **3410**
(знаков 2520); все **9** ссылок входят в полный отчёт целиком; показано:
YouTube 3, X 2, Telegram 3; скрыто: YouTube 12, X 13, Telegram 33 (15+15+36
сходятся с полным отчётом). Тесты — `tests/test_report_compact.py` (13).
