# ТЗ-39. Сводка 08:00: нумерация разделов без дыр

Дата: 18.09.2026. Модуль: `tuber/analysis/report.py` (`build_compact`).
База: коммит `88752d9` (ТЗ-38). Спеки: `docs/TZ-38-compact-drop-telegram.md` (убирает Telegram-раздел),
`docs/TZ-37-compact-viral-invariants.md`.

## 1. Дефект (мой замер на копии боевой базы, коммит 88752d9)

Сводка 18.09.2026 (3 884 байта) вышла с дырой в нумерации, потому что номера разделов записаны в коде
жёсткими строками, а Telegram-раздел из неё убран:

```
1. YouTube — топ по просмотрам/сутки: …
2. X — топ по лайкам: …
4. Виральные — охват против своей аудитории: …
5. Сквозной сюжет: сюжетов с материалами разных платформ — 12 …
```

Раздела «3.» нет — владелец читает «2», потом «4». Такой же дефект появится в обратную сторону, когда
Telegram вернут в сводку после маркировки каналов (D-52), если нумерацию снова править руками.

## 2. Что сделать

### 2.1. Номера разделов вычислять, а не печатать константой

- Собирать разделы сводки списком (заголовок, тело) и нумеровать их по порядку фактического вывода
  (`enumerate`), а не подставлять жёсткие «1.», «2.», «4.», «5.».
- Требование к результату: номера идут подряд `1, 2, …, N` без пропусков при ЛЮБОМ составе разделов —
  и когда Telegram скрыт (сейчас), и когда его вернут в сводку после D-52.
- Если раздел не печатается из-за отсутствия позиций (например, пустой X), нумерация остальных разделов
  остаётся сплошной; отсутствующий раздел не оставляет дыру.
- Формулировки заголовков не менять: YouTube — «YouTube — топ по просмотрам/сутки:», X — «X — топ по
  лайкам:», виральные — «Виральные — охват против своей аудитории:», сквозной сюжет — «Сквозной сюжет: …».

### 2.2. Полный отчёт не нумеровать заново

- Блоки полного отчёта (`1. Полезное`, `2. Фермы…`, `3. Новые продукты…`, `4. Истории с реакциями…`,
  `5. Telegram`) сохраняют свои номера и содержимое БЕЗ изменений: у него нумерация смысловая и
  разделы не исчезают.
- Выдача полного отчёта обязана совпасть с выдачей коммита `88752d9` на той же копии базы (time-dependent
  поля нормализовать: строка окна/времени, «лайки/час», счётчики «прошло полы» у пограничных по времени
  материалов).

### 2.3. Синхронизировать документацию внутри модуля

- Докстринг `build_compact` (там перечислены разделы с номерами, в том числе «раздел "4. Виральные…"»)
  переписать так, чтобы он не противоречил фактической нумерации.
