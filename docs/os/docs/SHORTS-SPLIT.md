# Разделение шортсов и полных видео (этап 8)

Документ фиксирует решения этапа 8. Ссылка на `METHODOLOGY-EXPANSION-SHORTS.md`
из ТЗ не подтвердилась: файла в `docs/` нет, поэтому обоснования собраны здесь.

## Дефект

YouTube с 15.10.2024 принимает шортсы длительностью до 3 минут. Контур считал
шортсом `duration <= 60`, из-за чего ролики 61–180 секунд попадали в поток
полных видео и портили сравнение: шортсы и полные видео — разные единицы
измерения.

## Что закреплено

* **Порог** `config.SHORTS_MAX_SECONDS` (по умолчанию 180, читается из
  окружения, `.env` подхватывается через `load_env`). Признак `is_shorts`
  документируется как **вероятный шортс по длительности**: надёжного
  API-признака шортса не существует.
* **`collect.is_short_duration(duration, cfg)`** — единая точка правила
  `0 < duration <= SHORTS_MAX_SECONDS`; используется `store_videos`.
* **`db.recompute_shorts(conn, cfg)`** — миграция существующего пула по
  сохранённому `duration_seconds`. Идемпотентна (меняет только отличившиеся
  строки), возвращает число изменённых. CLI: `python3 -m tuber migrate-shorts`.
* **Базовая линия по формату.** `channel_baseline` ключ `(channel_id, format)`,
  `format ∈ short|long`. `report._channel_median_views(..., fmt)` считает
  медиану только по своему формату и исключает самого кандидата;
  `outlier_score(conn, video_id, fmt)` сравнивает с медианой своего формата.
  Меньше `MIN_FORMAT_SAMPLE = 5` видео формата -> outlier `None`.
  `refresh_channel_baselines` материализует медианы в таблицу.
* **Замеры.** Свежие шортсы (< 48 ч) меряются не реже раза в 2 часа
  (`SHORTS_FRESH_INTERVAL_SECONDS`), полные — по прежним слотам 3–4 ч.
  Механизм слотов и уникальный индекс дедупликации не изменены.
* **Отчёт.** Публичные функции (`rising`, `dark_horses`, `by_topic`,
  `comment_leaders`, `ru_slice`) принимают `fmt`. `build_report` делит вывод на
  «## Шортсы» и «## Полные видео», смешанный рейтинг запрещён.
  CLI: `python3 -m tuber report --format short|long|all`.

## Ограничение живой базы

В боевой базе на момент проверки накоплено мало данных для рейтингов:
`video_classification.is_ai = 1` только у 12 видео, и на каждое приходится
один замер (`views_per_day` не посчитан). Поэтому блоки «Что растёт»,
«Тёмные лошадки» и другие честно пишут «нет данных», не подставляя нули.
Структура разделов при этом присутствует и корректна.
